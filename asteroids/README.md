# Asteroids

## This is a remake of the classic Asteroids game.

This game is written in Python and utilizes the pygame library. The development, up to object behavior and asteroid destruction, was an assignment from the [Boot.Dev]([https://website-name.com](https://github.com/bootdotdev/curriculum/blob/main/README.md)) program. I would like to add additional features in the future.

## Additional features to be added:
* Currently, the game is over once the player is hit by an asteroid. The screen remains frozen when this happens and pressing the 'y' key will restart the game, while pressing the 'n' key exits the program. Ideally, there would be a text box which tells the player this.
* The game should keep track of highest-scores and display them while the player is asked whether to replay.
* Multiple lives with the number visable to the player.
* A visible score.
* Power-ups or extra lives that spawn on the screen.
* Have objects wrap around the screen.
