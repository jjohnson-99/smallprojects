# A collection of small projects in Golang, Python, and hopefully other languages

These are some small, but fun, projects I've done in the past few months.

Asteriods, chirpy, gator, pokedexcli, and staticsite are projects from [Boot.Dev](https://www.boot.dev/dashboard).
They tell you what you should build in various steps, but don't tell you how besides giving some tips and hinting
at docs to read. I'll add other small projects as I do them.
